<span class="section-tag">Over mij</span>

<h2 class="section-title">Doreen Rey</h2>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">Ik geloof dat kwetsbaarheid de kracht heeft om de dynamieken in de wereld te beïnvloeden. Er is veel werk aan de winkel, collectief trauma is een feit. Als onze schaduwkanten en die van de samenleving steeds minder taboe worden en we collectief leren om de minder prettige gevoelens (boosheid, verdriet, pijn, angst) te voelen, dan zullen we ook steeds meer in contact komen met onze bron van onvoorwaardelijke liefde. Individueel, collectief, maatschappelijk.</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">Doorheen de processen om eigen trauma te helen -een non-stop proces- is muziek mijn medicijn. Ik zing over de groeipijnen op mijn ontdekkingstocht en de inzichten die daaruit voortkomen. Eigen trauma, collectief trauma en de pijn van de Aarde. Een andere overtuiging is dat muziek en samen zingen echte verbinding creëert. Dit is zo welkom in deze chaotische tijden van ontrafeling en <a href="https://andnowwhat.be/about/glossary/" target="_blank">collapse</a>.</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">Ik engageer me om steeds meer inzicht en bewustzijn op te bouwen over mijn eigen privileges, rang en macht, kolonisatie, genocides, intergenerationeel trauma, onderdrukking (menselijke en niet-menselijke wezens), overshoot en collapse, racisme,… Als mijn groeiend bewustzijn in vruchtbare grond verankert, kan ik het meer en meer uitdragen tijdens mijn workshops en concerten.</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">Langzaamaan zaden zaaien en componeren/composteren van de diepe verandering die ik in de wereld wil zien: het creëren van community, mensen samenbrengen om te zingen, rouwcirkels organiseren,… We moeten dit niet alleen doen!</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">In kinship!</p>

<span class="section-tag">About me</span>

<h2 class="section-title">Doreen Rey</h2>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">I believe vulnerability has the power to influence the dynamics of the world. There is much work to be made; collective trauma is a fact. If our shadow sides, and those of society, become less and less taboo, and if we collectively learn to feel the less pleasant emotions (anger, grief, pain, fear), we will also increasingly come into contact with our source of unconditional love. Individually, collectively, socially.</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">Through the processes of healing my own trauma — a non-stop process — music is my medicine. I sing about the growing pains of my journey of discovery and the insights that emerge from them. Personal trauma, collective trauma and the pain of the Earth. Another belief of mine is that music and singing together create real connection. This is so welcome in these chaotic times of unraveling and <a href="https://andnowwhat.be/about/glossary/" target="_blank">collapse</a>.</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">I am committed to continuously building insight and awareness around my own privileges, rank and power, colonization, genocides, intergenerational trauma, oppression (of human and non-human beings), overshoot and collapse, racism,… If my growing awareness is rooted in fertile ground, I can increasingly carry it into my workshops and concerts.</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">Little by little, sowing seeds and composing/composting the deep change I want to see in the world: creating community, bringing people together to sing, organizing grief circles,… We do not have to do this alone!</p>

<p style="color: var(--text-light); line-height: 1.8; margin-bottom: 1.2rem;">In kinship!</p>

function setLang(lang) {

  document.documentElement.lang = lang;

  document.querySelector('.lang-toggle').textContent = lang === 'nl' ? 'EN' : 'NL';

  document.querySelectorAll('[data-lang]').forEach(el => {

    el.classList.toggle('lang-hide', el.dataset.lang !== lang);

  });

}

function toggleLang() {

  setLang(document.documentElement.lang === 'nl' ? 'en' : 'nl');

}

document.addEventListener('DOMContentLoaded', () => setLang('nl'));


// DARK MODE

function toggleTheme() {

  const html = document.documentElement;

  const current = html.getAttribute('data-theme');

  const isDark = current === 'dark';

  html.setAttribute('data-theme', isDark ? 'light' : 'dark');

  localStorage.setItem('theme', isDark ? 'light' : 'dark');

  updateThemeIcon(!isDark);

}

function updateThemeIcon(isDark) {

  document.getElementById('theme-icon').innerHTML = isDark

    ? '<circle cx="12" cy="12" r="5"/><line x1="12" y1="1" x2="12" y2="3"/><line x1="12" y1="21" x2="12" y2="23"/><line x1="4.22" y1="4.22" x2="5.64" y2="5.64"/><line x1="18.36" y1="18.36" x2="19.78" y2="19.78"/><line x1="1" y1="12" x2="3" y2="12"/><line x1="21" y1="12" x2="23" y2="12"/><line x1="4.22" y1="19.78" x2="5.64" y2="18.36"/><line x1="18.36" y1="5.64" x2="19.78" y2="4.22"/>'

    : '<path d="M21 12.79A9 9 0 1 1 11.21 3 7 7 0 0 0 21 12.79z"/>';

}

(function initTheme() {

  const saved = localStorage.getItem('theme');

  const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;

  if (saved) {

    document.documentElement.setAttribute('data-theme', saved);

    updateThemeIcon(saved === 'dark');

  } else if (prefersDark) {

    updateThemeIcon(true);

  }

})();

// SMOOTH SCROLL FOR NAV LINKS

  a.addEventListener('click', e => {

    const target = document.querySelector(a.getAttribute('href'));

    if (target) {

      e.preventDefault();

      target.scrollIntoView({ behavior: 'smooth', block: 'start' });

      document.querySelector('.nav-links').classList.remove('open');

    }

  });

});
